# Security Policy

## Supported versions

Security fixes target the latest stable MINOR release only; earlier release lines are unsupported.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, tokens, personal data, local paths, logs, or exploit details in a public GitHub issue.

Use the repository's private **Report a vulnerability** flow:

https://github.com/hossamadellaw/hal-frontend-dashboard/security/advisories/new

Include the affected version, impact, reproduction steps, and any proposed mitigation. If GitHub does not offer the private reporting form, contact the repository owner through a verified private channel shown on the owner's GitHub profile and wait for acknowledgement before public disclosure.

Never send real production secrets or personal data in a report. Use redacted values and the smallest safe proof of concept.
